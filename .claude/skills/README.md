# Skills

Claude skills that ship with this repository. A session opened here loads them.

| Skill | What it is for |
|---|---|
| [`lake`](lake/SKILL.md) | Working in a Lake through its MCP server: design, train and ship in a workspace, data, agents, apps, services, repositories, usage. Copied from the skill every Lake serves at `/skills/lake/SKILL.md`, with two additions: using it with a Lake you installed, and a table of the development skills in the components |

To refresh the `lake` skill, fetch `https://lake.live/skills/lake/SKILL.md`, replace everything
between the two added sections with it, and keep the additions. Skills for changing a component's
code stay in that component's repository; link to them by full URL, do not copy them here.
