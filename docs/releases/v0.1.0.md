# Orama Lake v0.1.0

**Released 2026-11-16.** The first release of Orama Lake, the sovereign AI stack, published as open
source under the MIT licence. This repository holds no product source: a release is one set of
component versions that work together, pinned as git submodules. This page lists them, and
[`release.yaml`](../../release.yaml) carries the same set as a manifest the installer reads.

## Get it

```console
$ git clone --recurse-submodules --branch v0.1.0 https://github.com/oramasearch/lake-platform.git
```

Every submodule is fetched over HTTPS, so the clone needs no GitHub account or key. To install the
platform, start at [`docs/install/`](../install/README.md).

CRDT library, the full-text search library, the HTTP libraries) are pinned by those components.

Every component's images are on Docker Hub under `oramasearch/`, tagged with the version above.

## What it includes besides the pins

- **The release manifest**, [`release.yaml`](../../release.yaml), checked against the pins by
  `scripts/check-release-manifest.py`.
- **The installer**, [`install/install.sh`](../../install/README.md), and four install guides: Try it,
  Run it, Scale it and Air-gapped ([`docs/install/`](../install/README.md)).
- **The licence and contributor files:** `LICENSE` (MIT), `COPYRIGHT`, `THIRD_PARTY_LICENSES`,
  `SECURITY.md`, `CONTRIBUTING.md`, `CLA.md`, `CODE_OF_CONDUCT.md` and `TRADEMARKS.md`.
- **Governance:** [`GOVERNANCE.md`](../../GOVERNANCE.md) (Orama-led, with maintainers for each component,
  and RFCs for larger decisions), [`MAINTAINERS.md`](../../MAINTAINERS.md) and [`ROADMAP.md`](../../ROADMAP.md).
- **The agent guide** (`CLAUDE.md`) and the `lake` skill, so an agent can work with the platform:
  `claude`, then `/lake`.

## What it does not include

- **The one-command `try` image** (`lake-try`). Until it ships, [*Try it*](../install/try-it.md) runs the
  stack on a single-node k0s or k3s: directly on Linux, or in Docker on macOS and Windows.
- **Deferred work in the components:** each component's release notes list what it does not include
  and the pull requests deferred to a later release.

## Known issues

1. **Some images bundle GPL or LGPL userland** from their base images (Debian or Alpine), and a few
   binaries link LGPL libraries. Each component's notes name its own. They are being moved to static
   bases in later releases.
2. **k0s's embedded liquid build was not run to the end** with liquid v0.3.0; the clone of it is
   verified, the binary is not.
3. **The manifest's image digests are empty**, and `published` is `false`, until the images are
   signed. `lake-mcp-runner` is not pinned here.
4. **Each component's known issues** are on its own release page, linked above.
