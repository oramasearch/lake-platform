# Assets

Images used by the repository's own documents.

| File | What it is |
|---|---|
| `architecture-light.svg`, `architecture-dark.svg` | How Orama Lake fits together, for light and dark themes. Used in the root [`README.md`](../../README.md) |
| `architecture.py` | Generates both diagrams, so they never drift apart. Edit this file, then run `python3 docs/assets/architecture.py docs/assets` |
| `logo-light.svg`, `logo-dark.svg` | The Orama Lake logo: the O of Orama, holding a lake. For light and dark themes. Use it where the name is already beside it |
| `lockup-light.svg`, `lockup-dark.svg` | The logo with the name and the slogan, "The sovereign AI stack". Used at the top of the root [`README.md`](../../README.md). The words are set in the reader's system font |
| `logo.py` | Generates the logos and the lockups. Edit this file, then run `python3 docs/assets/logo.py docs/assets` |
